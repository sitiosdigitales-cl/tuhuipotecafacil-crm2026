# BUG-102 · La edición de comisiones aceptaba campos financieros calculados

Severidad: crítico  
Archivo: `src/app/api/comisiones/[id]/route.ts`  
Prueba: `tests/business/comision-update-controlled-fields.test.ts`

## Cómo reproducirlo

Enviar un `PUT` de comisión con `comisionTotal` u otra columna arbitraria. La
ruta transformaba y enviaba el objeto completo a Supabase, sin un contrato de
campos ni recálculo del total.

## Qué debería pasar

La API debe aceptar solo campos editables tipados. `comisionTotal` siempre debe
derivarse de `montoTotal` y `tasaComision` en el servidor; un valor recibido no
debe ignorarse silenciosamente, sino rechazarse para detectar integraciones
incorrectas.
