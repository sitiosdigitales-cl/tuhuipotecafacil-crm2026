# BUG-098 · Los logs de WhatsApp incluían secretos y datos de clientes

Severidad: crítico  
Archivos: `src/app/api/webhook/whatsapp/route.ts`, `src/lib/whatsapp.ts`  
Prueba: `tests/api/whatsapp-webhook-log-redaction.test.ts`

## Cómo reproducirlo

Fallar la verificación del webhook o recibir un mensaje desde un teléfono sin
lead. El servidor registraba el token presentado, el número telefónico y, para
mensajes procesados, el nombre y una parte del contenido. Los logs operativos
pueden conservarse y ser visibles para más personas que la ficha del cliente.

## Qué debería pasar

Los logs deben describir el evento y su resultado sin copiar secretos,
teléfonos, nombres, texto de conversaciones ni identificadores entregados por
el proveedor.
