# BUG-137 · Una cuenta legada activa no puede completar la recuperación

Severidad: alta
Archivo: `src/app/api/auth/recuperacion/route.ts`,
`supabase/migrations/20260818000000_recuperacion_password_turno.sql`
Prueba: `tests/auth/recuperacion-solicitud-neutra.test.ts`,
`supabase/tests/auth_identidad_pendiente.test.sql`

## Cómo reproducirlo

Configurar el modo `required` para una cuenta activa que todavía conserva el
hash legado y no tiene `auth_user_id`. El login la dirige a recuperación, pero
la ruta responde el mensaje neutro sin enviar correo y la RPC tampoco concede
el turno porque exige que la identidad ya esté enlazada.

## Qué debería pasar

La solicitud debe crear o reutilizar una identidad pendiente que todavía no
resuelva una sesión CRM. El hash legado se conserva hasta que la confirmación
promueve los metadatos y enlaza la identidad en una única operación de base.
El puente debe poder adoptar esa misma identidad sin dejar estados parciales.
