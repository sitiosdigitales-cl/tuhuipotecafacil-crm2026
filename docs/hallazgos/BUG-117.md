# BUG-117 · Una migración activa siembra una cuenta concreta

Severidad: crítico
Archivo: `supabase/migrations/20260815_usuario_diego_figueroa.sql`
Prueba: `tests/db/migration-no-user-credentials.test.ts`

## Cómo reproducirlo

Revisar la cadena ejecutable de `supabase/migrations/`. Uno de sus archivos
inserta una cuenta administrativa concreta junto con un hash reutilizable.

## Qué debería pasar

Las migraciones deben contener solamente estructura y transformaciones de datos
necesarias. El bootstrap de cuentas debe exigir credenciales entregadas en el
entorno de ejecución y nunca quedar versionado como SQL ejecutable.

## Corrección

Retirar la migración de la cadena activa y mantener el alta o recuperación
administrativa en `scripts/bootstrap-admin.mjs`. La persona responsable de la
operación debe rotar la credencial existente porque quitar el archivo no borra
el historial Git ni modifica producción.
