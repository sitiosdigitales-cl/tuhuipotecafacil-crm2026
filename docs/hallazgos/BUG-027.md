# BUG-027 · El webhook de email acepta remitentes anónimos

Severidad: crítico
Archivo: src/app/api/webhook/email/route.ts:93-221
Prueba: tests/api/email-webhook-auth.test.ts

## Cómo reproducirlo
Enviar JSON arbitrario a `POST /api/webhook/email` sin firma ni secreto crea un
lead mediante `supabaseAdmin`, inserta una notificación y envía un correo de
confirmación a la dirección controlada por quien hizo la petición.

## Qué debería pasar
Validar de forma obligatoria la firma del proveedor de email o un secreto
dedicado antes de parsear y escribir. Si la autenticación falta o falla, debe
responder 401 sin usar Supabase ni el proveedor de correo.
