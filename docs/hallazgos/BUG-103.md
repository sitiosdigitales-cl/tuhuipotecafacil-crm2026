# BUG-103 · La API de comisiones devuelve nombres de campo incompatibles

Severidad: alta
Archivo: src/lib/supabase.ts
Prueba: tests/lib/supabase-commission-columns.test.ts

## Cómo reproducirlo

Transformar una fila de `comisiones` leída desde Supabase. Campos como
`ejecutivoid`, `montototal` y `comisiontotal` conservan sus nombres en
minúsculas, aunque la interfaz y el módulo de negocio esperan camelCase.

## Qué debería pasar

La respuesta debe exponer `ejecutivoId`, `montoTotal`, `comisionTotal` y el
resto del contrato tipado para que la pantalla opere sobre los valores reales.
