# BUG-097 · Un script de usuarios contenía SQL inválido

Severidad: alto  
Archivo: `prisma/fix-usuarios-columns.sql`  
Prueba: `tests/db/sql-add-column-syntax.test.ts`

## Cómo reproducirlo

Ejecutar el script auxiliar para completar columnas de `usuarios`. La última
sentencia decía `ADD COLUMN IF NOT suspendidohasta`, construcción que PostgreSQL
no reconoce, y el script se detenía antes de crear esa columna.

## Qué debería pasar

Todas las adiciones idempotentes deben usar `ADD COLUMN IF NOT EXISTS`. El CI
debe revisar el patrón en cada archivo SQL de `prisma/` y `supabase/` para que
el mismo error no reaparezca.
