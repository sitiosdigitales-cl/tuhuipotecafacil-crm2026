# BUG-041 · El proxy produce una redirección circular para dos roles

Severidad: media
Archivo: src/proxy.ts:82
Prueba: tests/auth/proxy-route-access.test.ts

## Cómo reproducirlo

Abrir `/dashboard` con una sesión válida de rol `AGENTE` o `CLIENTE`. El proxy
responde `307` con `Location: /dashboard`. La siguiente petición recibe la
misma respuesta y la navegación no termina.

## Qué debería pasar

Cuando el rol no puede abrir una ruta, el destino debe ser diferente y debe
corresponder a una pantalla disponible para ese rol, o la aplicación debe
mostrar una respuesta explícita sin generar un ciclo.
