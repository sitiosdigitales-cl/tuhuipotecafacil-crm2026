# BUG-107 · El token de Google Calendar persiste en Web Storage

Severidad: crítica
Archivo: src/lib/services/googleCalendar.ts
Prueba: tests/security/google-calendar-token-storage.test.ts

## Cómo reproducirlo

Conectar Google Calendar y revisar `localStorage`. El token OAuth queda
guardado como `google_access_token`, sobrevive una recarga y está disponible
para cualquier script que se ejecute en el mismo origen.

## Qué debería pasar

El token debe permanecer solo en memoria del proceso del navegador. Tras una
recarga se solicita una autorización nueva y cualquier valor legado se elimina.
