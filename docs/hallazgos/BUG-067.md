# BUG-067 · El envío de correo confía en rol y destinatario del cliente

Severidad: alta
Archivo: src/app/api/email/send/route.ts
Prueba: tests/api/email-send-role-and-lead-scope.test.ts

## Cómo reproducirlo

Una sesión `CLIENTE` puede ejecutar cualquier tipo de envío. Cualquier sesión
puede indicar un destinatario distinto al correo registrado para el lead y los
envíos operativos no comprueban que el usuario trabaje con ese lead.

## Qué debería pasar

El catálogo y los envíos deben limitarse a los roles de trabajo. Cada correo
operativo debe referir un lead accesible para la sesión, y el servidor debe
obtener nombre y destinatario desde la ficha vigente. Las pruebas SMTP deben
quedar reservadas a administración.
