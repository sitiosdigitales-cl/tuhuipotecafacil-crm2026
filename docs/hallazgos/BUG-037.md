# BUG-037 · La ruta pública supera el presupuesto de JavaScript

Severidad: alta
Archivo: src/app/simulador-publico/page.tsx
Prueba: tests/performance/public-route-bundle.test.ts

## Cómo reproducirlo

Ejecutar `npm run build` y luego
`npm test -- tests/performance/public-route-bundle.test.ts`. Los manifiestos de
producción declaran `1.278.179` bytes de JavaScript moderno para
`/simulador-publico`: `851.424` bytes iniciales y `426.755` bytes de los
gráficos dinámicos.

## Qué debería pasar

Una ruta pública debe descargar como máximo `409.600` bytes (`400 KiB`) de
JavaScript. Los gráficos que todavía no se muestran no deben formar parte de
la descarga inicial.
