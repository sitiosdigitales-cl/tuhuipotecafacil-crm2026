# BUG-084 · Secretos concretos quedaron versionados y el script tenía fallback

Severidad: crítica
Archivo: docs/setup-vercel-env.md, scripts/backup-manual.sh
Prueba: tests/config/no-versioned-secret-defaults.test.ts

## Cómo reproducirlo

Leer la guía de Vercel o ejecutar el respaldo manual sin definir
`BACKUP_API_KEY`. La guía mostraba valores concretos y el script sustituía la
variable ausente por uno de ellos, en vez de detenerse.

## Qué debería pasar

El repositorio solo debe contener nombres de variables y marcadores. El script
debe terminar antes de llamar la API si no recibe una clave explícita. Como los
valores anteriores permanecen en el historial de Git, una persona responsable
de Vercel debe rotar `JWT_SECRET` y `BACKUP_API_KEY` antes del despliegue.
