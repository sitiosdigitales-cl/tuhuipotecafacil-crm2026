# BUG-003 · La API de bancos permite cambios sin sesión

Severidad: crítico
Archivo: src/app/api/bancos/route.ts:4-66
Prueba: tests/api/bancos-auth.test.ts

## Cómo reproducirlo
Sin cookie ni cabecera de autorización se pueden listar bancos y enviar POST,
PUT o DELETE para alterar tasas, convenios, contactos y requisitos.

## Qué debería pasar
Todas las operaciones deben rechazar la solicitud sin sesión con 401 antes de
consultar o modificar Supabase.
