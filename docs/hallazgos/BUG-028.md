# BUG-028 · El portal permite subir archivos a cualquier lead

Severidad: crítico
Archivo: src/app/api/portal/upload/route.ts:5-94
Prueba: tests/api/portal-upload-ownership.test.ts

## Cómo reproducirlo
Enviar a `POST /api/portal/upload` un PDF y el id de cualquier lead existente.
La ruta solo comprueba que ese id exista: no recibe RUT, sesión, firma ni token
que vincule al solicitante con el cliente, y guarda el archivo en su carpeta.

## Qué debería pasar
Requerir una prueba de acceso al portal vinculada al lead —idealmente un token
firmado, corto y de un solo propósito— antes de consultar datos, subir al bucket
o insertar el documento.
