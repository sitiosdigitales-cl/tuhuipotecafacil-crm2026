# BUG-087 · El correo informaba éxito sin realizar la entrega

Severidad: alta
Archivo: src/lib/email.ts
Prueba: tests/lib/email-delivery-config.test.ts

## Cómo reproducirlo
Ejecutar cualquier envío sin `RESEND_API_KEY`. La función registraba el mensaje
como simulado y devolvía `true`, por lo que la API respondía "Email enviado
correctamente" aunque ningún proveedor hubiera recibido la solicitud.

## Qué debería pasar
La ausencia de configuración debe producir un fallo visible para que la
interfaz no confirme una entrega inexistente. Una simulación local solo debe
ocurrir cuando se habilita de forma explícita.

## Corrección aplicada
Sin `RESEND_API_KEY`, la entrega devuelve `false`. En desarrollo se puede optar
por una simulación con `EMAIL_SIMULATION=true`; esa opción nunca se acepta en
producción y no registra destinatarios ni asuntos en consola.

## Acción operativa pendiente
Una persona con acceso a Vercel debe confirmar que `RESEND_API_KEY` y
`FROM_EMAIL` estén configuradas correctamente. El repositorio no puede
verificar ni modificar ese panel.
