# BUG-109 · La API de campañas no aplica los roles de marketing

Severidad: crítica
Archivo: src/app/api/campanas/route.ts
Prueba: tests/api/campaign-role-access.test.ts

## Cómo reproducirlo

Crear una sesión CLIENTE, AGENTE o EJECUTIVO y llamar a los métodos de
`/api/campanas`. La API acepta cualquier token válido aunque el módulo de
marketing declara acceso exclusivo para ADMIN y SUPER_ADMIN.

## Qué debería pasar

Listado, creación, edición, eliminación y navegación deben usar la misma matriz
administrativa y responder 403 para el resto de los roles.
