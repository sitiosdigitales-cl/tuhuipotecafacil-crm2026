# C-07 · Medición independiente de PERF-01 y PERF-02

Fecha: 2026-08-15
Build medido: `5795140`
Ruta: `/simulador-publico`

## Método

Se generó un build de producción y se midieron los archivos JavaScript que la
ruta declara en sus manifiestos de Next.js. El total de la ruta excluye el
polyfill para navegadores antiguos y suma:

- archivos iniciales de `build-manifest.json` y
  `page_client-reference-manifest.js`;
- archivos dinámicos de `react-loadable-manifest.json`;
- cada archivo una sola vez, según su tamaño real en `.next/`.

La comprobación se repitió con una petición HTTP al build de producción: los
scripts iniciales y dinámicos suman los mismos `1.278.179` bytes.

## Resultado

| Medición | Línea base | Estado después de PERF-01 y PERF-02 |
|---|---:|---:|
| JavaScript total en `.next/static/chunks` | 4,8 MB · 79 archivos | 4,810 MiB · 89 archivos |
| JavaScript moderno inicial de `/simulador-publico` | — | 831,5 KiB · 10 archivos |
| Gráficos dinámicos de la ruta | — | 416,8 KiB · 5 archivos |
| Total JavaScript de la ruta | 1.248 KB | 1.248,2 KiB · 15 archivos |

## Conclusión

La medición independiente confirma el resultado negativo de PERF-01: separar
los gráficos con `next/dynamic` creó archivos propios, pero no redujo la
descarga inicial observable de `/simulador-publico`. El tamaño global tampoco
muestra una reducción material respecto de la línea base redondeada.

PERF-02 busca reducir renders causados por identidades nuevas en los contextos;
el tamaño del bundle no permite confirmar ni descartar ese resultado. Debe
verificarse con una prueba de comportamiento separada.
