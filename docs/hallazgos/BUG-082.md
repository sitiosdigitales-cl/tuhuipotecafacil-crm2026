# BUG-082 · La carga confiaba solo en el tipo declarado del archivo

Severidad: alta
Archivo: src/app/api/upload/route.ts, src/app/api/portal/upload/route.ts
Prueba: tests/api/document-file-content.test.ts

## Cómo reproducirlo

Enviar contenido de texto con nombre `.pdf` y `Content-Type: application/pdf`.
Ambas rutas aceptaban esa declaración y continuaban hacia la base y Storage sin
comprobar que los bytes correspondieran a un formato permitido.

## Qué debería pasar

La carga debe verificar la firma real de PDF, JPEG, PNG y DOC. Un DOCX además
debe ser un paquete ZIP consistente con las entradas mínimas de Word, sin
macros, cifrado, rutas anómalas ni tamaño expandido desproporcionado.
