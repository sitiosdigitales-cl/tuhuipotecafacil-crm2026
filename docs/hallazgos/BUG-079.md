# BUG-079 · El asistente IA no limita rol, entrada ni coste

Severidad: alta
Archivo: src/app/api/chat/route.ts, src/lib/ai/estadisticas.ts
Prueba: tests/api/chat-guardrails.test.ts, tests/business/ai-context-minimization.test.ts

## Cómo reproducirlo

Cualquier sesión, incluido el portal cliente, puede llamar al proveedor con un
historial arbitrario, mensajes `system`, texto sin límite, sin cuota, timeout ni
tope de salida. El contexto automático también incluye nombre y RUT de clientes.

## Qué debería pasar

Solo roles internos deben consumir el servicio. La API debe validar mensajes de
texto, rechazar instrucciones de sistema, limitar tamaño, frecuencia, reintentos,
tiempo y tokens, desactivar telemetría de contenido y emitir el protocolo de
stream esperado por `useChat`. El resumen no debe incluir identificadores
directos de clientes.
