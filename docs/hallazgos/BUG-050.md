# BUG-050 · Comisiones no aplican la matriz de roles

Severidad: alta
Archivo: src/app/api/comisiones/route.ts:5-21
Prueba: tests/api/comisiones-role-access.test.ts

## Cómo reproducirlo

Iniciar una sesión con rol `EJECUTIVO`, `AGENTE` o `CLIENTE` y solicitar `GET`
o `POST /api/comisiones`. La API acepta la sesión, consulta Supabase y responde
con el listado o crea el registro, aunque la ruta `/comisiones` está reservada
a `SUPER_ADMIN` y `ADMIN` en el proxy.

## Qué debería pasar

Ambos métodos deben responder 403 antes de consultar Supabase cuando el rol no
sea `SUPER_ADMIN` o `ADMIN`. La API y la navegación deben aplicar la misma
matriz de roles.
