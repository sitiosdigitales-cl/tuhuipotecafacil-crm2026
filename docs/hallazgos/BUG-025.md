# BUG-025 · Un anónimo crea pagos para cualquier comisión

Severidad: crítico
Archivo: src/app/api/stripe/create-session/route.ts:5-58
Prueba: tests/api/stripe-create-session-auth.test.ts

## Cómo reproducirlo
Enviar `POST /api/stripe/create-session` sin cookie ni autorización permite
elegir monto, descripción, email, lead, ejecutivo y `comisionId`. Un pago real
de monto manipulado conserva esa metadata para que el webhook marque la
comisión indicada como pagada.

## Qué debería pasar
Responder 401 antes de consultar Stripe. Tras autenticar y autorizar, el
servidor debe obtener monto y relaciones desde la comisión persistida, no desde
campos controlados por el cliente.
