# BUG-078 · El webhook de leads funciona sin secreto configurado

Severidad: crítica
Archivo: src/app/api/webhook/leads/route.ts, crm-webhook-plugin.php
Prueba: tests/api/leads-webhook-secret.test.ts

## Cómo reproducirlo

Sin `ELEMENTOR_WEBHOOK_SECRET`, una solicitud al webhook se procesa igualmente.
Además, el secreto se acepta por query string, el plugin envía aunque no esté
configurado y el formulario público llama al mismo canal servidor a servidor.

## Qué debería pasar

El webhook debe quedar inactivo si falta un secreto fuerte, aceptar únicamente
la cabecera del servidor WordPress y comparar su valor en tiempo constante. El
formulario del navegador debe usar el endpoint público de pre evaluación sin
recibir ni conocer el secreto compartido.
