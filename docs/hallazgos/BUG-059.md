# BUG-059 · Conversaciones no respetan participantes ni roles

Severidad: crítica
Archivo: src/app/api/conversaciones/route.ts; src/app/api/conversaciones/[id]/route.ts
Prueba: tests/api/conversation-participant-scope.test.ts

## Cómo reproducirlo

Con una sesión válida, consultar la colección devuelve todas las conversaciones
si no se envía un filtro, y el filtro `participante` acepta cualquier ID. El
detalle y la edición tampoco comprueban que la sesión pertenezca al hilo. Al
crear, `creadoPor` y la lista de participantes se copian íntegramente del cuerpo.

## Qué debería pasar

El servidor debe derivar el usuario actual desde la sesión, limitar colección y
detalle a sus hilos, aplicar el catálogo de roles y registrar siempre al creador
real como participante. `SUPER_ADMIN` conserva la vista global definida para la
administración del sistema.
