# BUG-142 · Los simuladores rotulan tasas fijas como datos CMF

Severidad: alta
Archivo: `src/app/(dashboard)/simulador/page.tsx`, `src/app/simulador-publico/page.tsx`
Prueba: `tests/api/bank-manual-rates.test.ts`

## Cómo reproducirlo

Abrir cualquiera de los simuladores. Ambos contienen una lista fija de bancos y
porcentajes, pero la interfaz los describe como tasas reales publicadas por la
CMF y les asigna la fecha actual, aunque no existe una consulta al organismo.

## Qué debería pasar

Los simuladores deben usar únicamente el catálogo de tasas cargado manualmente
por el equipo, mostrarlo como referencial y quedar sin cálculo cuando no haya
tasas vigentes. La API CMF debe permanecer en `SIN_DATOS`.

## Impacto

Una persona puede interpretar una cifra antigua o de demostración como dato
oficial vigente. La fecha de pantalla tampoco demuestra cuándo fue confirmada.
