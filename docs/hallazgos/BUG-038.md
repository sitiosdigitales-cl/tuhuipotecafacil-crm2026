# BUG-038 · La pantalla de permisos conserva roles eliminados

Severidad: media
Archivo: src/app/(dashboard)/permisos/page.tsx
Prueba: tests/ui/role-catalog-regression.test.tsx

## Cómo reproducirlo

Abrir `/permisos`. La lista “Roles del Sistema” todavía muestra `Gerente` y
`Visor`, aunque ya no forman parte del tipo `Rol`, y no muestra `Ejecutivo`,
que sí es un rol vigente.

## Qué debería pasar

La interfaz debe usar el catálogo consolidado de roles. No debe ofrecer
configuraciones para roles eliminados y debe incluir `EJECUTIVO`.
