# BUG-032 · Un agente abre la ficha de otro vendedor por ID

Severidad: crítico
Archivo: src/app/api/leads/[id]/route.ts:5-12
Prueba: tests/api/lead-detail-agent-read-isolation.test.ts

## Cómo reproducirlo
Iniciar sesión como `AGENTE` y llamar a `GET /api/leads/<id-ajeno>` con el ID de
un lead cuyo `asignadoa` pertenece a otro vendedor. La ruta devuelve la ficha
completa sin comparar su propietario con el `userId` de la sesión.

## Qué debería pasar
Responder 403, o un 404 que no revele existencia, y no devolver datos del lead.
