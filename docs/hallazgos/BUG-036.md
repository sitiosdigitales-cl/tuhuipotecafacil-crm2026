# BUG-036 · Una versión anual cubre también el requisito de otro año

Severidad: alto
Archivo: src/modulos/documentos/config.ts:97-102
Prueba: tests/business/document-checklist-completeness.test.ts

## Cómo reproducirlo
Construir el checklist de un independiente o una empresa dejando fuera un
documento anual requerido, pero manteniendo la versión del otro año con el mismo
`tipo`. `buscarDocSubido` acepta primero el tipo exacto y ambos requisitos quedan
marcados como presentes.

## Qué debería pasar
Cuando varios requisitos comparten `tipo`, distinguirlos también por sus grupos
de búsqueda o por un identificador específico; si falta un año, el checklist no
debe contar como completo.
