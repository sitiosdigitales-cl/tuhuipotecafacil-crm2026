# BUG-111 · Biblioteca ignora los roles administrativos de marketing

Severidad: alta
Archivo: src/app/api/biblioteca/route.ts
Prueba: tests/api/library-role-access.test.ts

## Cómo reproducirlo

Usar una sesión CLIENTE, AGENTE o EJECUTIVO para listar, crear, editar o borrar
recursos de `/api/biblioteca`. Los cuatro métodos aceptan cualquier token,
aunque el catálogo de marketing reserva el módulo a administración.

## Qué debería pasar

API y navegación deben responder 403 a roles no administrativos y aplicar la
misma matriz que el menú y `MARKETING_PERMISOS`.
