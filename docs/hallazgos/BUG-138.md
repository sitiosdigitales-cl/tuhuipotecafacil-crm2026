# BUG-138 · La identidad enlazada conserva el claim pendiente

Severidad: media
Archivo: src/app/api/auth/recuperacion/confirmacion/route.ts:112
Prueba: scripts/ci/recovery-http-integration.mjs

## Cómo reproducirlo

Crear una cuenta legada, completar la recuperación contra Supabase local y
consultar `app_metadata` de la identidad resultante. Supabase combina las
claves enviadas a `updateUserById`, por lo que agregar `crm_user_id` no retiraba
el valor anterior de `crm_pending_user_id`.

## Qué debería pasar

Una identidad enlazada debe conservar `crm_user_id` y retirar el identificador
pendiente para que Auth y `public.usuarios` representen el mismo estado final.
