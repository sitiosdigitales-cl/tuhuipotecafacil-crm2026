# BUG-118 · Dos migraciones comparten la misma versión

Severidad: alto
Archivo: `supabase/migrations/`
Prueba: `tests/db/migration-filenames.test.ts`

## Cómo reproducirlo

Levantar Supabase desde una base vacía. La CLI aplica la primera migración con
prefijo `20260815` y luego no puede registrar la segunda porque la versión es la
clave primaria del historial.

## Qué debería pasar

Cada archivo debe usar un timestamp de 14 dígitos único para que la cadena pueda
aplicarse y auditarse en el mismo orden en todos los entornos.

## Corrección

Renombrar todas las migraciones antiguas con timestamps completos y actualizar
las referencias documentales y de pruebas.
