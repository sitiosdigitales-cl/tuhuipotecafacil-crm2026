# BUG-077 · Vitest depende de un cargador que quedará incompatible

Severidad: media
Archivo: vitest.config.ts, package.json
Prueba: tests/config/vitest-native-config.test.ts

## Cómo reproducirlo

Cada ejecución de pruebas avisa que la configuración usa sintaxis ESM cargada
como CommonJS y que `vite-tsconfig-paths` ya fue reemplazado por la resolución
nativa de Vite. El próximo cargador nativo no admite esa combinación.

## Qué debería pasar

Vitest debe cargar una configuración ESM explícita y resolver los alias de
TypeScript con Vite, sin un complemento obsoleto ni advertencias preventivas.
