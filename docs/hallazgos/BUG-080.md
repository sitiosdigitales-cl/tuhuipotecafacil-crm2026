# BUG-080 · El portal cliente puede aprobar y borrar documentos

Severidad: alta
Archivo: src/app/api/documentos/[id]/route.ts
Prueba: tests/api/document-controlled-mutations.test.ts

## Cómo reproducirlo

Una sesión `CLIENTE` asociada al lead supera la comprobación de cartera y puede
enviar `estado: APROBADO` o ejecutar `DELETE`. Cualquier rol con acceso también
puede escribir nombre, ruta del archivo, autor y fecha de aprobación provistos
por el cuerpo.

## Qué debería pasar

El cliente debe limitarse a consultar y subir antecedentes. Solo roles internos
pueden revisar o eliminar; el PUT acepta estados del catálogo y observaciones,
y deriva autor y fecha de aprobación desde la sesión y el servidor.
