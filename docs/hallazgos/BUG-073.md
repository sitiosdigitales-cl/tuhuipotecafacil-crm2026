# BUG-073 · Las APIs del CRM consultan Supabase con la clave anónima

Severidad: crítica
Archivo: src/lib/supabase.ts
Prueba: tests/lib/supabase-admin-fail-closed.test.ts

## Cómo reproducirlo

Todas las rutas importan `supabase` desde el módulo compartido. Ese cliente se
crea con `NEXT_PUBLIC_SUPABASE_ANON_KEY`, de modo que las APIs dependen de las
mismas políticas amplias que el navegador y no pueden cerrar acceso anónimo
sin dejar de funcionar.

## Qué debería pasar

Como el navegador ya consume solo APIs, la fachada de base debe ser
`server-only`, lazy y respaldada por service role. La importación no debe exigir
variables durante el build, pero la primera consulta debe fallar cerrado si la
configuración privilegiada no existe.
