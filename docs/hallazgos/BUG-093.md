# BUG-093 · Las sesiones admitían una clave de firma débil

Severidad: crítico  
Archivo: `src/lib/jwt.ts`  
Prueba: `tests/auth/jwt-secret-strength.test.ts`

## Cómo reproducirlo

Configurar `JWT_SECRET` con uno o pocos caracteres y solicitar una nueva
sesión. El servidor emitía y aceptaba el token sin distinguir esa configuración
de una clave aleatoria adecuada.

## Qué debería pasar

La autenticación debe cerrarse ante una configuración ausente o menor a 32
caracteres. Producción debe usar un valor aleatorio exclusivo, generado como
indica `docs/setup-vercel-env.md`, y no reutilizar claves de respaldos o
webhooks.
