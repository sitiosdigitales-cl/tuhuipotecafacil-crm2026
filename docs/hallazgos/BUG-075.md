# BUG-075 · Las políticas SQL permiten todas las filas y documentos públicos

Severidad: crítica
Archivo: prisma/run-all-pending.sql
Prueba: tests/db/rls-deny-anon-migration.test.ts

## Cómo reproducirlo

Los SQL históricos crean políticas `USING (true)` y `WITH CHECK (true)` para
datos de clientes, mensajería, integraciones y documentos. El bucket
`documentos` se declara público y varias tablas se agregan a Realtime.

## Qué debería pasar

Con todas las consultas ya detrás de APIs server-only, los roles `anon` y
`authenticated` no necesitan privilegios sobre `public`. La migración debe
habilitar RLS, eliminar políticas heredadas, conservar service role, retirar
replicación y volver privados los buckets sensibles.
