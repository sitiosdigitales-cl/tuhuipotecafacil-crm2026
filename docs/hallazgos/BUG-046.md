# BUG-046 · El listado de respaldos responde fuera de sesión

Severidad: media
Archivo: src/app/api/backup/route.ts:84
Prueba: tests/api/route-session-coverage.test.ts

## Cómo reproducirlo

Solicitar `GET /api/backup` sin cookie. El método consulta Storage y devuelve
los nombres, fechas y tamaños de los respaldos. A diferencia de `POST` y
`DELETE`, tampoco exige la clave del proceso automático.

## Qué debería pasar

El listado debe comprobar una sesión administrativa antes de consultar
Storage, o aplicar explícitamente el mismo control del proceso automático.
