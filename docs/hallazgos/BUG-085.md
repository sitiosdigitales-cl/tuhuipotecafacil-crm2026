# BUG-085 · Cabeceras contradictorias y permisos globales demasiado amplios

Severidad: alta
Archivo: vercel.json, next.config.ts, public/formulario-leads.html
Prueba: tests/config/security-headers.test.ts

## Cómo reproducirlo

Comparar las reglas de Vercel y Next. El formulario recibía simultáneamente
`ALLOWALL` y `DENY`, además de `frame-ancestors *`. Todas las rutas `/api`
publicaban CORS para cualquier origen aunque el CRM las consume en mismo origen.
El mensaje de ajuste del iframe también se enviaba con destino `*`.

## Qué debería pasar

Debe existir una sola política. El panel no se puede enmarcar; el formulario
solo puede hacerlo desde `tuhipotecafacil.cl`, `www.tuhipotecafacil.cl` o su
mismo origen. Las APIs no publican CORS global y el mensaje del iframe usa el
origen padre comprobado.
