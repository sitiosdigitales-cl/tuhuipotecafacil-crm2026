# BUG-076 · Dependencias con avisos vigentes no se revisan en CI

Severidad: alta
Archivo: package.json, .github/workflows/ci.yml
Prueba: tests/config/dependency-hardening.test.ts

## Cómo reproducirlo

`npm audit --omit=dev` informa ocho avisos altos y tres moderados. Entre ellos
está la versión directa `next@16.2.10`. Además, utilidades de desarrollo se
instalan como dependencias de producción y GitHub Actions no ejecuta auditoría.

## Qué debería pasar

La aplicación debe usar una versión corregida de Next, separar las herramientas
de desarrollo, retirar paquetes móviles ya sin código consumidor y hacer fallar
CI ante avisos moderados de producción o altos del ciclo de entrega.
