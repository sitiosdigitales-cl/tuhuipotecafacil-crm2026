# BUG-136 · GitHub Actions conserva el runtime Node 20 obsoleto

Severidad: media
Archivo: `.github/workflows/*.yml`
Prueba: `tests/config/github-actions-runtime.test.ts`

## Cómo reproducirlo

Ejecutar la prueba de contrato sobre los workflows encuentra referencias a
`actions/checkout@v4` y `actions/setup-node@v4`. GitHub informa en cada job que
esas acciones todavía declaran Node 20 y que temporalmente las fuerza a Node 24.

## Qué debería pasar

Los workflows deben usar las versiones oficiales que ya ejecutan sus acciones
con Node 24, sin cambiar el Node 22 fijado para compilar y probar la aplicación.
