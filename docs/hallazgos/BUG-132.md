# BUG-132 · El servicio CMF publicaba tasas fijas como datos oficiales

Severidad: crítica
Archivo: `src/lib/cmf/service.ts`
Prueba: `tests/integrations/cmf-fail-closed.test.ts`

## Comportamiento observado

Tres endpoints públicos y el asistente presentaban ocho cifras escritas en el
código como tasas vigentes e históricas de la CMF. La actualización esperaba
100 milisegundos, devolvía el mismo arreglo y reportaba el servicio como activo.
También existía un catálogo por banco con condiciones y CAE sin procedencia
verificable.

## Comportamiento esperado

Una cifra financiera debe provenir de una respuesta verificable de la fuente y
conservar fecha, tipo y estado de consulta. Si la integración oficial no está
configurada, los endpoints deben responder “no disponible” y el asistente no
debe incorporar una estimación bajo la etiqueta CMF.

## Impacto

Una simulación, comparación o respuesta del asistente podía fundamentarse en
cifras sin respaldo y presentarlas como información del regulador. La decisión
financiera resultante no era trazable.

## Corrección

Se retiraron las tablas fijas y los estados de actualización simulados. Mientras
no se implemente y configure el consumo autenticado de la API oficial, tasas e
histórico responden 503, el estado queda `SIN_DATOS` y el asistente advierte que
no hay datos oficiales. La API CMF requiere una clave por consulta según su
[documentación oficial](https://api.cmfchile.cl/documentacion/index.html).
