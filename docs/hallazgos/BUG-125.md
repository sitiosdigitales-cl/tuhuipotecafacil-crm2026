# BUG-125 · Plantillas simulaba edición sin usar la API

Severidad: alta
Archivo: `src/app/(dashboard)/plantillas/page.tsx`
Prueba: `tests/ui/templates-read-only.test.ts`

## Comportamiento observado

Los modales de crear y guardar se cerraban sin enviar datos. Eliminar quitaba la
fila solo del estado local. Además, la pantalla esperaba `activa`, `uso`,
`imagenes` y `flujos`, propiedades que no existen en el contrato versionado de
la tabla `plantillas`.

## Comportamiento esperado

La interfaz no debe confirmar ni aparentar una mutación hasta que el editor use
la API, valide el mismo esquema que PostgreSQL y trate sus respuestas de error.
El catálogo de lectura debe usar únicamente campos persistidos.

## Impacto

Una persona podía perder cambios creyendo que habían sido guardados, mientras
que una fila real podía romper el render al no contener las métricas esperadas
por la pantalla.

## Corrección

La página ahora carga y normaliza el catálogo real, filtra por tipo, muestra
`variables` y `usos`, y conserva la vista previa aislada. Crear, editar y
eliminar quedan ocultos hasta implementar un editor verificable.
