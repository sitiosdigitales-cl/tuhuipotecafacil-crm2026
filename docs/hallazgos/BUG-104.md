# BUG-104 · Comisiones mezcla registros reales con cifras de demostración

Severidad: crítica
Archivo: src/app/(dashboard)/comisiones/page.tsx
Prueba: tests/ui/commissions-real-data.test.tsx

## Cómo reproducirlo

Abrir `/comisiones`. Aunque la pantalla consulta `/api/comisiones`, las
secciones de créditos y pagos muestran nombres, RUT, bancos y montos definidos
como constantes en el navegador. Además, el bloque por ejecutivo aparece dos
veces y el botón de edición solo cambia estado local.

## Qué debería pasar

Una pantalla financiera debe mostrar únicamente registros persistidos. Toda
acción presentada como guardada debe terminar correctamente en la API antes de
actualizar la interfaz.
