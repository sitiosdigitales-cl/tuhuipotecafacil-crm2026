# BUG-096 · El login ignoraba fallos al guardar intentos

Severidad: crítico  
Archivo: `src/app/api/auth/login/route.ts`  
Prueba: `tests/auth/login-attempt-persistence.test.ts`

## Cómo reproducirlo

Hacer que Supabase resuelva el `UPDATE` de `intentosfallidos` con un objeto
`{ error }`. La promesa se cumple normalmente, por lo que el manejador usado
solo para rechazos de promesa no se ejecutaba. La API respondía igual aunque el
contador o su limpieza no se hubieran escrito.

## Qué debería pasar

El login debe comprobar el resultado de cada escritura. Si no puede persistir
el contador, no debe aparentar que el control funciona ni emitir una sesión;
además debe dejar un mensaje operativo en los logs sin incluir credenciales.
