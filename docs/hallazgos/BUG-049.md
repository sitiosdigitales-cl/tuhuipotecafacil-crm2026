# BUG-049 · Las cuentas inhabilitadas todavía pueden iniciar sesión

Severidad: alta
Archivo: src/app/api/auth/login/route.ts:55
Prueba: tests/auth/login-account-status.test.ts

## Cómo reproducirlo

Mantener una contraseña válida para un usuario cuyo `estado` sea `INACTIVO` o
`SUSPENDIDO` y enviar sus credenciales a `POST /api/auth/login`. La ruta lee el
estado, pero continúa y entrega las dos cookies de sesión.

## Qué debería pasar

Sólo una cuenta con estado `ACTIVO` debe iniciar sesión. Las demás deben recibir
una respuesta de rechazo y ninguna cookie de sesión.
