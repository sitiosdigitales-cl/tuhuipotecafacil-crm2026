# BUG-121 · El respaldo no permite recuperar el CRM completo

Severidad: crítica
Archivo: `src/lib/backup.ts`
Prueba: `tests/backup/external-backup-workflow.test.ts`

## Cómo reproducirlo

Crear un respaldo desde el panel y revisar su contenido. El archivo contiene
solamente filas de `leads` y `documentos`, no incluye el esquema, las demás
tablas, identidades ni los objetos binarios. Además se conserva dentro del mismo
proyecto Supabase.

## Qué debería pasar

Cada hora debe generarse un conjunto portable de roles, esquema y datos, copiar
los objetos privados, verificar su integridad y enviarlo cifrado a una cuenta R2
independiente. La activación y los secretos deben permanecer bajo control humano.

## Corrección

Agregar un workflow desactivado por defecto que use la CLI fijada de Supabase,
un manifiesto verificable de Storage y Restic cifrado hacia Cloudflare R2.
