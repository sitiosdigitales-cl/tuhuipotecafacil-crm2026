# BUG-145 · La revisión de documentos acepta JSON sin límite

Severidad: alta
Archivo: `src/app/api/documentos/[id]/route.ts`
Prueba: `tests/api/document-update-input-validation.test.ts`

## Cómo reproducirlo

Enviar a `PUT /api/documentos/:id` un cuerpo sobredimensionado o un campo que
no pertenece al contrato de revisión. La ruta leía el JSON completo antes de
validar únicamente el estado y las observaciones.

## Qué debería pasar

La revisión debe aceptar solo JSON de hasta 8 KiB y validar el contrato antes
de escribir el estado del documento.
