# BUG-047 · El catálogo interno de emails responde fuera de sesión

Severidad: baja
Archivo: src/app/api/email/send/route.ts:157
Prueba: tests/api/route-session-coverage.test.ts

## Cómo reproducirlo

Solicitar `GET /api/email/send` sin cookie. El método responde 200 con el
catálogo de plantillas que consume la configuración interna del CRM.

## Qué debería pasar

El catálogo debe comprobar una sesión antes de responder, igual que el método
`POST` del mismo endpoint.
