# Cola de hallazgos

Un archivo por hallazgo, nombrado `<ID>.md`. Nunca un archivo compartido: así
dos hallazgos simultáneos no producen conflicto de merge.

Codex crea el archivo con la prueba fallando. Claude marca la segunda casilla
cuando la prueba queda en verde y referencia el ID en su commit.

Plantilla en `docs/agentes/PROTOCOLO.md`, sección 4.
