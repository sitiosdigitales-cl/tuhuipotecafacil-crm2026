# BUG-135 · El piping conservaba datos del correo en un log temporal

Severidad: alta
Archivo: `wordpress/email-handler.php`
Prueba: `tests/wordpress/email-handler-log-privacy.test.ts`

## Comportamiento observado

El script registraba remitente, destinatario, asunto y la respuesta completa
del CRM. Esa respuesta incluye el nombre y correo extraídos. Ante un fallo de
parseo también escribía la estructura completa del mensaje. El destino por
omisión es el directorio temporal del sistema.

## Comportamiento esperado

El registro del proceso debe contener solo estados técnicos y códigos HTTP,
sin campos del mensaje ni cuerpos de respuesta. El archivo debe crearse con
permisos privados y serializar escrituras concurrentes.

## Impacto

Datos personales de clientes podían persistir fuera del CRM, con retención y
acceso distintos a los definidos para la aplicación.

## Corrección

El log conserva únicamente tamaño, etapas y estado HTTP, usa bloqueo de
escritura y queda en modo `0600`. También se retiró una llamada obsoleta que
emitía advertencias al ejecutar el handler con PHP 8.5.
