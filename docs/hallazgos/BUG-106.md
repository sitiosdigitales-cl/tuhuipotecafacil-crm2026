# BUG-106 · Campañas muestra indicadores fijos aunque consulta la API

Severidad: alta
Archivo: src/app/(dashboard)/campanas/page.tsx
Prueba: tests/ui/campaigns-real-metrics.test.tsx

## Cómo reproducirlo

Abrir `/campanas` con cualquier conjunto de filas en Supabase. El listado usa
esas filas, pero el total, ROI, aperturas, clics, conversiones y presupuesto
provienen de constantes. La vista también ofrece botones de crear, editar,
pausar y exportar que no persisten ninguna acción.

## Qué debería pasar

Los indicadores deben derivarse de la respuesta real y la interfaz no debe
presentar acciones como funcionales mientras no exista una operación conectada
al servidor.
