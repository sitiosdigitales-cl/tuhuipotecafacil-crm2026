# BUG-071 · El cliente admin cae silenciosamente al cliente anónimo

Severidad: crítica
Archivo: src/lib/supabase.ts
Prueba: tests/lib/supabase-admin-fail-closed.test.ts

## Cómo reproducirlo

Iniciar el servidor sin `SUPABASE_SERVICE_ROLE_KEY`. La exportación
`supabaseAdmin` pasa a ser exactamente el cliente anónimo, por lo que los
webhooks y escrituras internas continúan con permisos distintos a los esperados.

## Qué debería pasar

El cliente privilegiado vive en un módulo solo servidor, sin exportarse desde
el módulo compartido. Cuando falta URL o service role debe detener la operación
con un error de configuración; nunca debe reutilizar credenciales anónimas.
