# BUG-099 · El correo podía informar éxito tras un rechazo del proveedor

Severidad: crítico  
Archivo: `src/lib/email.ts`  
Prueba: `tests/lib/email-delivery-config.test.ts`

## Cómo reproducirlo

Hacer que `Resend.emails.send()` resuelva con `{ data: null, error }`. El SDK
no rechaza necesariamente la promesa en ese caso; la función ignoraba el campo
`error`, devolvía `true` y escribía el destinatario en los logs.

## Qué debería pasar

La función debe devolver `false` cuando el proveedor rechaza la entrega y
registrar solo el resultado operativo, sin direcciones de correo ni el objeto
completo del proveedor.
