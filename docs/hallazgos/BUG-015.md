# BUG-015 · Las configuraciones de integraciones se exponen sin sesión

Severidad: crítico
Archivo: src/app/api/integraciones/route.ts:5-12
Prueba: tests/api/integraciones-auth.test.ts

## Cómo reproducirlo
Enviar `GET /api/integraciones` sin cookie ni autorización ejecuta
`select("*")` y devuelve también `configuracion`, una columna JSONB destinada a
guardar API keys y secretos de proveedores externos.

## Qué debería pasar
Responder 401 antes de consultar Supabase y no devolver secretos ni siquiera a
usuarios autenticados que solo necesitan ver el estado de la integración.
