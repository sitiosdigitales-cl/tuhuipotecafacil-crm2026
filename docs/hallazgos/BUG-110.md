# BUG-110 · Automatización ignora su matriz de roles en la API

Severidad: crítica
Archivo: src/app/api/flujos/route.ts
Prueba: tests/api/automation-role-access.test.ts

## Cómo reproducirlo

Usar una sesión CLIENTE, AGENTE o EJECUTIVO sobre flujos, triggers, plantillas
o sus historiales. Las 16 operaciones solo comprueban que exista un token y
permiten leer o mutar la configuración y sus contadores.

## Qué debería pasar

Lectura, creación, edición, eliminación, historiales y navegación deben aplicar
`AUTOMATIZACION_PERMISOS`: administración gestiona el módulo y solo
SUPER_ADMIN elimina.
