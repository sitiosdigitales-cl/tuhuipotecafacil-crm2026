# BUG-008 · Un endpoint de prueba escribe con service role

Severidad: crítico
Archivo: src/app/api/notificaciones/test/route.ts:1-22
Prueba: tests/api/notificaciones-test-endpoint.test.ts

## Cómo reproducirlo
Enviar `GET /api/notificaciones/test` sin cookie ni autorización inserta una
notificación mediante `supabaseAdmin` y devuelve el registro creado. La ruta
se incluye en el build de producción.

## Qué debería pasar
La ruta interna de prueba no debe formar parte de la aplicación de producción.
