# BUG-040 · Un fallo al listar respaldos se muestra como lista vacía

Severidad: alta
Archivo: src/app/(dashboard)/backups/page.tsx:32
Prueba: tests/ui/backup-load-error.test.tsx

## Cómo reproducirlo

Abrir `/backups` cuando `GET /api/backup` responde `500` con
`success: false`. Al terminar la carga, la pantalla muestra “No hay respaldos
disponibles” y “Último Respaldo: Ninguno”.

## Qué debería pasar

La interfaz debe distinguir un fallo de consulta de una respuesta exitosa sin
registros. Ante `500` debe mostrar el mensaje de error y no afirmar que no hay
respaldos.
