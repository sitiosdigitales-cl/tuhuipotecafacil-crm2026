# BUG-039 · El portal confirma un perfil que no se guardó

Severidad: alta
Archivo: src/componentes/portal/PortalClienteContent.tsx:233
Prueba: tests/portal/profile-save-error.test.tsx

## Cómo reproducirlo

Entrar al portal con una sesión de cliente, abrir “Mi Perfil”, editar los datos
y guardar mientras `PUT /api/leads/[id]` responde `500`. La interfaz cierra la
edición, actualiza los datos locales y muestra “Perfil actualizado
correctamente”.

## Qué debería pasar

La interfaz debe comprobar `response.ok`. Ante una respuesta `500` debe
mantener la edición abierta, conservar los datos escritos y mostrar un mensaje
de error, sin confirmar un guardado que el servidor no realizó.
