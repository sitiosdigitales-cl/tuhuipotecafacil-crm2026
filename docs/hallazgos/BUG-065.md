# BUG-065 · Cualquier sesión puede leer o fabricar la auditoría

Severidad: crítica
Archivo: src/app/api/auditoria/route.ts
Prueba: tests/api/audit-log-role-and-write-surface.test.ts

## Cómo reproducirlo

Una sesión de cualquier rol puede listar hasta 200 registros. También puede
enviar un POST definiendo `usuarioId`, nombre, acción, valores, IP y dispositivo;
el servidor copia esos datos como si fueran un registro confiable.

## Qué debería pasar

Solo `ADMIN` y `SUPER_ADMIN` deben consultar el registro. No debe existir una
escritura pública que acepte identidad y hechos definidos por el cliente; los
eventos se insertarán desde servicios internos que ya conozcan al actor real.
