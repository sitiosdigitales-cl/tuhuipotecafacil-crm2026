# BUG-007 · Las notificaciones se leen y alteran sin sesión

Severidad: crítico
Archivo: src/app/api/notificaciones/route.ts:5-111
Prueba: tests/api/notificaciones-auth.test.ts

## Cómo reproducirlo
Sin enviar cookie ni autorización, `GET /api/notificaciones` devuelve las
notificaciones de todos los usuarios. En las mismas condiciones, `PUT` puede
marcarlas todas como leídas y `DELETE` elimina cualquier id conocido.

## Qué debería pasar
Responder 401 antes de consultar Supabase y limitar las operaciones posteriores
a las notificaciones que pertenecen al usuario autenticado.
