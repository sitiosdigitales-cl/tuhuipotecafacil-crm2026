# BUG-069 · El dispatcher interno se expone como endpoint genérico

Severidad: alta
Archivo: src/app/api/notificaciones/despachar/route.ts
Prueba: tests/api/notification-dispatch-surface.test.ts

## Cómo reproducirlo

Cualquier sesión puede solicitar un evento, título, descripción y usuario
destino. El endpoint llama al dispatcher que también puede activar correo y
WhatsApp. El único helper que lo referencia no tiene consumidores en el repo.

## Qué debería pasar

El despacho multicanal debe permanecer como operación interna de las rutas de
negocio, donde ya existen el rol y el contexto del recurso. No debe existir una
entrada genérica desde el navegador cuando ningún flujo funcional la necesita.
