# BUG-115 · El panel confirmaba respaldos que nunca ejecutaba

Severidad: alta
Archivo: src/app/(dashboard)/configuracion/_components/tab-sistema.tsx
Prueba: tests/ui/system-settings-real-actions.test.ts

## Cómo reproducirlo

Abrir Configuración, entrar a Sistema y pulsar Crear Respaldo, Exportar Datos,
Limpiar Caché u Optimizar Base de Datos. Cada botón esperaba uno a tres segundos
y mostraba un mensaje de éxito sin llamar una API ni modificar el sistema. La
misma pantalla además identificaba la base como MySQL, aunque la aplicación usa
PostgreSQL en Supabase.

## Qué debería pasar

La interfaz solo debe confirmar operaciones cuyo resultado verificó. La gestión
de exportaciones debe llevar a la pantalla que llama a `/api/backup`; una acción
sin implementación no debe aparecer como disponible. La tecnología mostrada
debe coincidir con la infraestructura real.

## Corrección aplicada

Se retiraron los controles simulados y la zona de restablecimiento inexistente.
El panel ahora enlaza a `/backups`, describe el alcance limitado de esa
exportación e identifica correctamente PostgreSQL y Supabase Storage.
