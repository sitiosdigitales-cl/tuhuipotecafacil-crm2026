# BUG-009 · El listado de documentos se expone sin sesión

Severidad: crítico
Archivo: src/app/api/documentos/route.ts:6-18
Prueba: tests/api/documentos-auth.test.ts

## Cómo reproducirlo
Enviar `GET /api/documentos` sin cookie ni autorización devuelve los metadatos
de todos los documentos. También acepta `leadId` para enumerar los de un
cliente concreto e incluye la URL almacenada del archivo.

## Qué debería pasar
Responder 401 antes de consultar Supabase y filtrar después por los leads que
el usuario autenticado puede ver.
