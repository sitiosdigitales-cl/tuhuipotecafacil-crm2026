# BUG-053 · La ruta duplicada de registro reemplaza la sesión administradora

Severidad: crítica
Archivo: src/app/api/auth/register/route.ts:1-48
Prueba: tests/api/legacy-register-route.test.ts

## Cómo reproducirlo

Crear una cuenta mediante `POST /api/auth/register` con una sesión
administrativa. La respuesta genera un token para la cuenta recién creada y
sobrescribe `auth_token`, por lo que la siguiente navegación usa la identidad
nueva. La interfaz vigente crea cuentas mediante `POST /api/usuarios`; no hay
consumidores de la ruta duplicada en el repositorio.

## Qué debería pasar

Debe existir una sola API administrativa para crear usuarios. El alta no debe
cambiar la identidad de quien la ejecuta ni mantener dos políticas de roles que
puedan divergir.
