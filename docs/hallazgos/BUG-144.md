# BUG-144 · La creación de comisiones procesa JSON sin contrato acotado

Severidad: alta
Archivo: `src/app/api/comisiones/route.ts`
Prueba: `tests/api/commission-create-input-validation.test.ts`

## Cómo reproducirlo

Enviar a `POST /api/comisiones` un cuerpo sobredimensionado, un período
fraccionario o campos que no forman parte de una comisión. La ruta leía el JSON
completo y validaba únicamente monto y tasa mediante conversiones parciales.

## Qué debería pasar

La ruta debe limitar el cuerpo a 8 KiB, exigir JSON y aceptar únicamente el
contrato tipado de creación antes de calcular o consultar la base.
