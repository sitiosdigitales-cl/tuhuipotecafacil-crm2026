# BUG-042 · El pipeline acepta coincidencias parciales de etiquetas

Severidad: alta
Archivo: src/modulos/leads/validaciones-pipeline.ts:99
Prueba: tests/business/pipeline-validations.test.ts

## Cómo reproducirlo

Validar el avance a `DOCS_COMPLETAS` con la etiqueta
`docs-completos-pendiente`, o a `APROBADO` con `no-aprobado-banco`. Las dos
transiciones quedan habilitadas aunque ninguna etiqueta coincide con el valor
requerido completo.

## Qué debería pasar

Las etiquetas se almacenan como valores separados por comas. La regla debe
comparar cada valor completo y mantener bloqueada la transición cuando sólo
existe una coincidencia parcial.
